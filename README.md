# Bi Koltuk

Berberler için online randevu uygulamasının web sitesi. GitHub Pages üzerinden yayınlanır; Google Play'deki uygulama da bu siteyi açar.

- `config.js`: Supabase bağlantısı, uygulama adı ve iletişim bilgileri
- `gizlilik.html`: gizlilik politikası ve KVKK aydınlatma metni
- `hesap-silme.html`: hesap ve veri silme
- `.well-known/assetlinks.json`: Android uygulamasının bu siteye bağlanması (Play paketinden sonra doldurulur)
